# フォント変更エフェクト（YMM4 プラグイン）

テキストアイテムやボイスアイテムの字幕に挿すだけで、フォント・文字サイズ・文字間隔・行間・文字色・装飾を
**エフェクト側の値で上書き**して描画する YMM4 映像エフェクトです。

- ボイスアイテムの字幕は「字幕の映像エフェクト」に挿します。キャラクター設定の字幕エフェクトに挿せば、
  そのキャラクターのセリフ字幕すべてに一括で適用できます。
- 字幕が「キャラクター設定を使う」「個別設定」のどちらでも、実際に使われている設定を元に上書きします。
- アイテム・キャラクター本体の設定は書き換えません。エフェクトを無効化・削除すれば元の見た目に戻ります。
- 上書きする項目ごとに「〜を変更」スイッチがあり、オンにした項目だけが上書きされます。
- サイズ・文字間隔・行間はアニメーション（移動・中間点など）に対応しています。
- グループ制御のエフェクトとして使うと、配下のテキストアイテムをまとめて上書きできます。

## 上書きできる項目

| グループ | 項目 | 既定 |
| --- | --- | --- |
| フォント | フォント | 変更する |
| | 太字 / イタリック | 変更しない（オン／オフで強制） |
| | サイズ | 変更しない |
| 文字間隔・行間 | 文字間隔 / 行間 | 変更しない |
| 色・装飾 | 文字色 | 変更しない |
| | 装飾（縁取り等）と装飾色 | 変更しない |
| 詳細 | 部分指定も上書き | オン（リッチテキストで部分的に指定したフォント・文字間隔も上書き） |

## 仕組みと注意点

映像エフェクトは本来、描画済みの画像しか受け取れません。このプラグインは
親アイテム（ボイスアイテムの場合は字幕をテキストアイテムに変換したもの）の複製に上書き値を適用し、YMM4 標準のテキスト描画で描き直した画像に差し替えています。

- **エフェクト一覧の一番上に置いてください。** 前段にあるエフェクトの効果は描き直しで失われます。
- 対象はテキストアイテムとボイスアイテムの字幕です。それ以外のアイテムに挿した場合は何もしません（素通し）。
- 「文字毎に個別オブジェクト」にも対応しています。合字などで文字の分割数が元フォントと変わる場合、
  増えた分は表示されず、減った分は空になります。
- 同じアイテムに複数挿した場合は、下にあるもの（後に適用されるもの）の設定が有効です。

## 動作環境

- ゆっくりMovieMaker4（YMM4 v4.55 以降を推奨）
- .NET 10 ランタイム（YMM4 本体に準拠）

## インストール

1. [Releases](https://github.com/bluemistel/YMM4-FontEffect/releases) から最新の `FontEffect.v.<バージョン>.ymme` をダウンロード
2. `.ymme` をダブルクリック（または YMM4 のウィンドウにドラッグ＆ドロップ）
3. インストール画面で「このプラグインの開発者を信頼する」にチェックし「インストール」
4. YMM4 を再起動

手動で配置する場合は、`.ymme` を ZIP として展開し、`FontEffect` フォルダごと `（YMM4フォルダ）\user\plugin\` に置いてください。

## 使い方

- テキストアイテム：映像エフェクトに「テキスト」→「フォント変更」を追加
- ボイスアイテムの字幕：字幕の映像エフェクトに「フォント変更」を追加
- キャラクター全体：キャラクター設定の字幕エフェクトに「フォント変更」を追加

追加したら、上書きしたい項目の「〜を変更」をオンにして値を設定します（フォントは最初からオン）。

## ビルド

.NET 10 SDK と開発用 YMM4（既定: `C:\tools\YukkuriMovieMaker_Dev\`）が必要です。

```bash
dotnet build -c Release
```

ビルド後、`<YMM4>\user\plugin\FontEffect\` に自動コピーされます。
YMM4 の場所が違う場合は `-p:YMM4DirPath=D:\path\to\YMM4\` を付けてください。

配布用 `.ymme` の作成:

```bash
dotnet build -c Release -p:PackYmme=true
```
